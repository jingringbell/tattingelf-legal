# TattingElf — Legal & Support pages

Static pages for the TattingElf iPad app, published via GitHub Pages.

- `index.html` — Privacy Policy
- `support.html` — Support / FAQ

## After publishing

Update the placeholder `__CONTACT_EMAIL__` in `index.html` and `support.html` with the real
support address, then commit and push.

## URLs to use in App Store Connect

- Privacy Policy URL: `https://<username>.github.io/<repo>/`
- Support URL: `https://<username>.github.io/<repo>/support.html`
